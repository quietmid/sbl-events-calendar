# Breikkiliitto Event Calendar Wix App

The goal of this project is to create an accessible, user-friendly calendar on our website where people can find all breaking events in one place.

Currently, breakdance events are mostly posted on Instagram and occasionally Facebook. While active members of the scene know where to look, newcomers and outsiders struggle to find this information. This project is my solution for Finland, with the long-term goal of serving the Nordics and Baltics.

The feature will include week and month views, filter through categories, and allow user submissions "hopefully!".
